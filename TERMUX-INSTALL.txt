SCHOOL MANAGEMENT v4 — ANDROID / TERMUX QUICK START

Use a new folder for the v4 rebuild. This focused version provides student records, exams, weekly timetable, and JSON backup/restore. It does NOT include the legacy authentication, attendance, staff, CSV/PDF, or LAN-sync features.

1) In Termux, allow storage access if needed:
   termux-setup-storage

2) Install Node.js and unzip:
   pkg update
   pkg install nodejs unzip

3) Put the repository ZIP in Downloads, then extract it into a fresh folder:
   mkdir -p ~/storage/downloads/SchoolManagement-v4
   unzip -o ~/storage/downloads/school-management-rebuild.zip -d ~/storage/downloads/SchoolManagement-v4
   cd ~/storage/downloads/SchoolManagement-v4

4) Confirm the root contains App.js, package.json, index.js, and app.json:
   ls -l App.js package.json index.js app.json

5) Install dependencies and run the static check:
   npm install
   npm run check

6) Start Expo:
   npx expo start --clear

Use the Expo Go QR/connection flow printed by Expo. Press w in the Expo terminal to start the web target where supported.

Troubleshooting:
- If App.js cannot be resolved, run pwd and verify you are in the extracted project root.
- If installation is interrupted, retry npm install.
- If package compatibility errors occur, inspect Expo's recommended package versions before applying npx expo install --fix.

Important:
- Android data is stored in the app-local SQLite database; web data is stored in that browser's local storage. They do not sync.
- Export backups regularly and keep them private.
- This is a development starter. Authentication, role permissions, encrypted storage, remote backups, and physical-device/browser acceptance tests are still required before use with real student data.
